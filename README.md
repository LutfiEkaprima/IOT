
# IOT Project Website

## Deskripsi
Aplikasi ini adalah platform monitoring dan kontrol sistem IoT berbasis web. Pengguna dapat melihat status sensor, alarm, dan koneksi, serta mengatur notifikasi dan preferensi alarm.

## Fitur Utama
- **Monitoring Sensor**: Tampilkan data sensor secara real-time.
- **Alarm System**: Indikator alarm dan pengaturan alarm.
- **Status Koneksi**: Status koneksi ke server MQTT.
- **Notifikasi**: Pengaturan dan izin notifikasi.
- **Pengaturan**: Ubah preferensi aplikasi melalui tab pengaturan.

## Struktur Folder
- `app/` : Halaman utama dan layout aplikasi
- `assets/` : Gambar dan suara
- `components/` : Komponen UI seperti kartu sensor, indikator alarm, dsb.
- `contexts/` : Context React untuk state global
- `hooks/` : Custom hooks untuk logika aplikasi
- `types/` : Tipe data TypeScript

## Instalasi
1. **Clone repository**
	```powershell
	git clone https://github.com/LutfiEkaprima/IOT.git
	cd IOT
	```
2. **Install dependencies**
	```powershell
	npm install
	```
3. **Jalankan aplikasi**
	```powershell
	npm start
	```

## Konfigurasi
- Ubah pengaturan MQTT dan alarm di file konfigurasi atau melalui halaman pengaturan aplikasi.

## Teknologi
- React / React Native
- TypeScript
- MQTT
